# Lab 8: The Central Dogma — DNA to Protein

## Overview

In this lab, you will model the flow of genetic information: DNA Replication, Transcription, and Translation. You will act as the cellular machinery to copy DNA, transcribe it into mRNA, and translate it into a functional protein sequence.

## Learning Objectives

1. Model DNA replication to produce two semi-conservative daughter strands.
2. Transcribe a DNA sequence into mRNA using complementary base pairing rules.
3. Translate an mRNA sequence into a polypeptide using the genetic code table.
4. Predict the effect of mutations (substitution, insertion, deletion) on the final protein.

## Activity

* **Replication Race:** Speed-replicate a DNA strand using magnetic nucleotide models.
* **Transcription & Translation Simulation:** Decode a "gene" to build a physical protein model (e.g., using colored beads as amino acids).
* **Mutation Analysis:** Introduce specific mutations and determine if they are silent, missense, or nonsense.
