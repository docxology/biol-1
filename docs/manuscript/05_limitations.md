# Limitations and conclusion {#sec:limitations}

A matched object ID certifies byte identity within the audited Git tree. A
format extension supports counting a distribution pair and does not guarantee
equal formatting or content between the PDF and DOCX versions. File names and
object IDs provide no evidence of instructional quality, accessibility,
student outcomes, or private-source publication completeness. We did not open,
execute, or render teaching assets.

The inventory demonstrates that the two bulk views cover the organized public
files at the audited revision. It also distinguishes the observed file
structure from the private publisher's content and release checks.
