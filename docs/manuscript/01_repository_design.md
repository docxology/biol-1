# Repository design {#sec:repository-design}

The student journey begins at the syllabus and schedule, then proceeds to the
individual module bundles. Each module brings together resources for that topic.
Top-level category collections serve readers who need one resource type across
the course. The flat and all-files views support bulk access [@friedman2026biol1].

This design gives a reader several routes to the same resource. To characterize
what each route contains, the study measures paths, file formats, and object
identity separately. A PDF and an editable DOCX count as separate files when
their contents differ. More than one path can locate a byte-identical file.
