# Using the distribution {#sec:using-the-distribution}

Students can choose a resource by topic in the module bundles or browse one
category across the course. The syllabus and schedule determine ordering and
due dates. Dashboard availability complements the print materials. Bulk views
support collection-wide access, while a category or module path gives a direct
resource locator for citation or discussion [@friedman2026biol1].

The inventory gives maintainers a structural check after regeneration. A future
revision can add or remove file objects even when directory names remain the
same. Changes in path counts and changes in distinct-object counts warrant
separate interpretation.
