# Abstract {#sec:abstract}

BIOL-1 is a public distribution of College of the Redwoods General Biology course
materials [@friedman2026biol1]. We inventoried a fixed public revision to
distinguish navigational coverage from duplicated distribution paths. The study
uses committed paths and Git object IDs, with no reads of teaching-file contents.

The publication contains module bundles and separate category collections.
Every module has a quiz in both supported handout formats. Both bulk views
contain the same set of file objects as the organized resource collections.
Bulk paths and distinct file objects measure different aspects of the
distribution.
