# Publication and distribution

This public repository contains the generated BIOL-1 course distribution for
College of the Redwoods, Pelican Bay. The private authoring repository owns the
module definitions, handout sources, publication configuration, and source-level
validation. It copies the public landing README and agent guidance from its
publication resources. Coordinate future edits to those two files with the
private authoring copies. The documented generator does not copy this public
`docs/` tree from that location.

| Public path | Role |
| --- | --- |
| [`course/`](../course/) | Syllabus and schedule |
| [`modules/`](../modules/) | Bundles arranged by module |
| `module-NN-*/` | Module quiz format pairs |
| [`homework/`](../homework/), [`module_keys/`](../module_keys/), [`slides/`](../slides/) | Course resources by category |
| [`labs/`](../labs/), [`dashboards/`](../dashboards/), [`practice_tests/`](../practice_tests/), [`review_materials/`](../review_materials/) | Handouts, optional interactive resources, and review sets |
| [`full_flat/`](../full_flat/), [`ALL_FILES/`](../ALL_FILES/) | Bulk distribution views |

Practice-test keys and module study keys are public study resources. The
maintainer policy keeps exams, exam answer keys, accommodations, and private
institutional material in the authoring repository. The
[public inventory](manuscript/README.md) checks file and distribution coverage
from Git metadata. It does not replace the private publisher's content checks.

For reuse and attribution, see the [course guide](course-guide.md),
[license](../LICENSE), and [citation metadata](../CITATION.cff).
