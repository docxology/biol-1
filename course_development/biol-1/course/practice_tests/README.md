# Practice Tests

This directory contains practice tests for **BIOL-1: Biology 1** (Pelican Bay Prison, Spring 2026).

## Structure

- `practice-test-XX.md` - Practice test with questions
- `practice-test-XX_key.md` - Answer key with explanations

## Module Coverage

- **Practice Test 01**: Modules 1–4 (Study of Life through Cells)
- **Practice Test 02**: Modules 5–6 (Membranes and Metabolism)
- **Practice Test 03**: Modules 7–11 (Exam 02 preparation)
- **Practice Test 04**: Modules 12–15 (Exam 03 preparation)
- **Practice Test 05**: Modules 1–15 (comprehensive final review)

## Usage

Both practice tests and answer keys are published to `PUBLISHED/biol-1/practice_tests/`.
Students can use these for self-assessment before exams.
