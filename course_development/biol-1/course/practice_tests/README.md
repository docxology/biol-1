# Practice Tests

This directory contains practice tests for BIOL-1 (Principles of Biology).

## Structure

- `practice-test-XX.md` - Practice test with questions
- `practice-test-XX_key.md` - Answer key with explanations

## Module Coverage

- **Practice Test 01**: Modules 1-4 (Study of Life through Cells)
- **Practice Test 02**: Modules 5-17 (Membranes through Evolution)

## Usage

Both practice tests and answer keys are published to `PUBLISHED/biol-1/practice_tests/`.
Students can use these for self-assessment before exams.
