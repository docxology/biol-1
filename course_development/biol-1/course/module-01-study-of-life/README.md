# Module 01: Biology: The Study of Life

## Overview

What makes something alive? This module introduces the shared properties that define life — cells, energy use, response to stimuli, reproduction, regulation, and evolution — and the scientific process biologists use to test claims about living systems.

## Topics

1. What counts as life
2. Science as a way of testing
3. Organization from cells to ecosystems
4. Evidence, variables, and measurement
5. How biological explanations improve

## Learning Objectives

By the end of this module, you should be able to:

1. Distinguish living systems from nonliving examples using multiple characteristics.
2. Separate hypotheses, predictions, observations, and conclusions in a scientific test.
3. Place biological examples at the correct scale of organization.
4. Identify variables and evidence in a simple investigation.
5. Revise a biological explanation when new evidence appears.

## Key Terms

- Cell
- Homeostasis
- Metabolism
- Hypothesis
- Variable
- Evidence
- Theory
- Evolution
