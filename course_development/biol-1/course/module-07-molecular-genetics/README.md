# Module 07: Molecular Genetics

## Overview

DNA stores the instructions for life. This module covers DNA structure and base-pairing, semiconservative replication, transcription and translation (the central dogma), and how mutations connect molecular changes to traits.

## Topics

1. DNA structure
2. Replication
3. Transcription
4. Translation
5. Mutation and gene expression evidence

## Learning Objectives

By the end of this module, you should be able to:

1. Describe DNA structure and base-pairing rules.
2. Explain why DNA replication is semiconservative.
3. Compare transcription and translation.
4. Use codons to connect mRNA sequence to amino acid sequence.
5. Explain how mutation can alter protein and trait outcomes.

## Key Terms

- DNA
- Nucleotide
- Replication
- Transcription
- Translation
- Codon
- Mutation
- Gene expression
