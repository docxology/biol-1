# Module 09: Inheritance Genetics

## Overview

How are traits passed from parents to offspring? This module covers alleles and genotype, Mendelian inheritance patterns, Punnett-square probability prediction, inheritance beyond simple dominance, and pedigree analysis.

## Topics

1. Alleles and genotype
2. Mendelian patterns
3. Punnett-square prediction
4. Beyond simple dominance
5. Pedigrees and probability

## Learning Objectives

By the end of this module, you should be able to:

1. Distinguish gene, allele, genotype, and phenotype.
2. Use segregation to explain monohybrid inheritance.
3. Build and interpret Punnett-square probabilities.
4. Recognize inheritance patterns beyond complete dominance.
5. Use pedigree evidence to reason about traits.

## Key Terms

- Gene
- Allele
- Genotype
- Phenotype
- Dominant
- Recessive
- Punnett square
- Pedigree
