# Module 03: Organic Molecules

## Overview

Carbon is the backbone of life. This module explores how carbon skeletons, polymerization, and the four major macromolecule classes — carbohydrates, lipids, proteins, and nucleic acids — build and run living systems.

## Topics

1. Carbon skeletons
2. Building and breaking polymers
3. Carbohydrates and lipids
4. Proteins and shape
5. Nucleic acids and information

## Learning Objectives

By the end of this module, you should be able to:

1. Explain why carbon is central to biological molecule diversity.
2. Distinguish monomers, polymers, dehydration synthesis, and hydrolysis.
3. Compare the functions of carbohydrates and lipids.
4. Connect protein shape to protein function and denaturation.
5. Describe how nucleic acids encode biological information.

## Key Terms

- Organic molecule
- Monomer
- Polymer
- Carbohydrate
- Lipid
