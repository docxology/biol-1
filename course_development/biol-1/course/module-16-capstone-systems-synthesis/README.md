# Module 16: Capstone Systems Synthesis

## Overview

This capstone module connects the full arc of BIOL-1 — from molecules to ecosystems — into one systems view. You will learn to trace mechanism chains across biological scales, identify feedback loops and tradeoffs, and build evidence-backed explanations that synthesize concepts from multiple modules.

## Topics

1. Biology across scales
2. Mechanism chains
3. Feedback and constraint
4. Evidence from multiple modules
5. Capstone explanation and revision

## Learning Objectives

By the end of this module, you should be able to:

1. Connect concepts from at least three modules in one explanation.
2. Trace a mechanism across biological scales.
3. Identify feedback loops, constraints, and tradeoffs.
4. Match evidence types to claims at different scales.
5. Revise a systems explanation using new evidence.

## Key Terms

- System
- Scale
- Mechanism
- Feedback loop
- Constraint
- Tradeoff
- Synthesis
- Evidence chain
