## Overview

Gregor Mendel discovered that traits are inherited in predictable patterns. By crossing pea plants and counting thousands of offspring, he uncovered the fundamental rules of genetics — rules that apply to all living things, including humans. In this lab you will master those rules step by step: learn the core vocabulary, practice with Punnett squares, and then apply what you know to increasingly complex inheritance patterns — from simple dominance, to codominance and multiple alleles, to sex-linked and polygenic traits.

## Part 1: Key Concepts & Mendel's Laws

*Before solving genetics problems, you need the language. Study the reference definitions below, then answer the questions that follow.*

### Reference Definitions

| Term | Definition |
|------|------------|
| **Gene** | A segment of DNA that codes for a specific trait |
| **Allele** | A version of a gene (e.g., a brown-eye allele vs. a blue-eye allele) |
| **Diploid** | Having **two copies** of each chromosome — one from each parent — so you carry **two alleles** for every gene |
| **Genotype** | The alleles an organism carries, written with letters (e.g., *Aa*) |
| **Phenotype** | The physical trait you can observe (e.g., "brown eyes") |
| **Homozygous** | Two identical alleles (*AA* or *aa*) |
| **Heterozygous** | Two different alleles (*Aa*) — also called a **carrier** if the trait is recessive |
| **Dominant** | The allele expressed when at least one copy is present (capital letter, e.g., **A**) |
| **Recessive** | The allele expressed only when two copies are present (lowercase letter, e.g., **a**) |
| **Punnett Square** | A grid used to predict the offspring of a genetic cross |

## Part 2: Coin Toss — Modeling Allele Segregation

> **Learning Goal:** Experience how random chance during meiosis determines which allele each parent passes on.

When a parent with genotype **Aa** makes gametes (sperm or eggs), each gamete randomly receives either **A** or **a**. This is like flipping a coin — a 50/50 chance for each allele. By simulating this process, you will see how probability governs inheritance.

### Procedure

1. Get **two coins**. One coin represents the **Father (Aa)**. The other represents the **Mother (Aa)**.
2. Flip both coins simultaneously **20 times**. For each flip, record the offspring genotype:
   - **Heads** = Dominant allele (**A**)
   - **Tails** = Recessive allele (**a**)
   - Both Heads = **AA** · One Head + One Tail = **Aa** · Both Tails = **aa**

## Part 6: ABO Blood Types — Codominance & Multiple Alleles

*The ABO blood system is a real-world example of both **codominance** (Iᴬ and Iᴮ are codominant — both expressed) and **multiple alleles** (three alleles exist in the population: Iᴬ, Iᴮ, i).
