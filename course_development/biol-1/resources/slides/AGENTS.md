# Technical Documentation: Slides

## Technical Specifications

This directory follows the standard `cr-bio` repository structure for `resources` items. Active slide PDFs must use `module-N-slides-*.pdf` where `N` is an active BIOL-1 module number (1-16). Do not keep out-of-range slide files in this directory; historical slide snapshots live under `archive/spring-2026/`.

The current active slide inventory intentionally has no decks for modules 12, 13, or 15. Missing decks are safer than publishing a mismatched chapter deck under the wrong active module number.
