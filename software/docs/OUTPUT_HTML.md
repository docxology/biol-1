# Output Format: HTML

> **Navigation**: [README](README.md) | [Orchestration](ORCHESTRATION.md) | [PDF](OUTPUT_PDF.md) | [DOCX](OUTPUT_DOCX.md) | [HTML](OUTPUT_HTML.md) | [Audio](OUTPUT_AUDIO.md) | [Dashboards](DASHBOARD_FORMAT.md)

Detailed specification for all HTML outputs generated by the cr-bio pipeline. The system produces **four HTML-related artifacts** (each is HTML on disk), plus **optional normalized Markdown** study-guide copies that are **not** HTML—see [Normalized Markdown study guides](#normalized-markdown-study-guides-not-html) below.

---

## HTML Output Types

| Type | Generator Module | Purpose | Interactivity |
|------|-----------------|---------|---------------|
| **Simple HTML** | `format_conversion` | Static readable version of content | None |
| **Interactive Website** | `html_website` | Full single-page app per module | High |
| **Lab HTML** | `lab_manual` | Fillable lab worksheets | Medium |
| **Dashboard HTML** | Manual authoring | Canvas-based visualizations | Very High |

---

## 1. Simple HTML

Basic Markdown → HTML conversion for static viewing.

| Property | Value |
|----------|-------|
| **Extension** | `.html` |
| **Generator** | `format_conversion` via `markdown2` |
| **Features** | Clean semantic HTML, minimal CSS |

```python
from src.format_conversion.main import convert_file
convert_file("input.md", "html", "output.html")
```

### Output Structure

```
module-XX/output/
├── study-guides/
│   ├── keys-to-success.html   ← Simple HTML
│   └── questions.html         ← Simple HTML
```

---

## 2. Interactive Website

Full-featured single-page application generated per module.

| Property | Value |
|----------|-------|
| **Extension** | `index.html` (in website/ directory) |
| **Generator** | `html_website` module |
| **Dependencies** | `batch_processing`, `format_conversion` |

### Features

| Feature | Description |
|---------|-------------|
| 🗂️ Sidebar Navigation | Collapsible sidebar with quick links |
| ↔️ Resizable Split-View | Draggable handle for sidebar/content |
| 🌙 Dark Mode | Toggle persists via `localStorage` |
| ⬆️ Back to Top | Scroll button |
| 📱 Mobile Responsive | Touch-friendly with toggleable menu |
| 🖨️ Print Friendly | Clean print output |
| ♿ Accessibility | Skip nav, high contrast |
| 🎧 Embedded Audio | MP3 players per section |
| ✅ Interactive Quizzes | MC, T/F, matching, free response |

### Generation

```python
from src.html_website.main import generate_module_website

generate_module_website(
    module_path="/path/to/module",
    output_dir="/path/to/output/website",
    course_name="BIOL-8"
)
```

### Output Structure

```
module-XX/output/
└── website/
    └── index.html   ← Interactive website
```

**`PUBLISHED/` mirror:** Category reorganization (**`reorganize_to_categories`**) removes per-module `index.html` from the published tree while moving study guides into **`homework/`** and **`module_keys/`**. Treat the interactive site as a **development artifact** unless you add a separate deploy path.

## 3. Lab HTML

Interactive fillable lab worksheets with auto-save.

| Property | Value |
|----------|-------|
| **Extension** | `.html` |
| **Generator** | `lab_manual` module |
| **Features** | Fillable fields, auto-save, print button |

### Features

| Feature | Description |
|---------|-------------|
| ✏️ Fillable Fields | Text inputs and text areas |
| 📊 Data Tables | Interactive tables with editable cells |
| 💾 Auto-Save | Progress saved to `localStorage` |
| 🔄 Load/Clear | Restore or clear saved data |
| 🖨️ Print | Print-optimized layout |

### Generation

```python
from src.lab_manual.main import render_lab_manual

render_lab_manual(
    "lab-01.md", "lab-01.html",
    output_format="html",
    course_name="BIOL-8"
)
```

See [LAB_FORMAT.md](LAB_FORMAT.md) for the complete lab authoring guide.

## 4. Dashboard HTML

Standalone Canvas-based interactive visualizations. These are **manually authored** HTML files (not auto-generated).

| Property | Value |
|----------|-------|
| **Extension** | `.html` |
| **Location** | `course_development/biol-{1,8}/course/labs/dashboards/` (relative to course root) |
| **Generator** | Manual authoring |
| **Features** | Canvas animations, simulations, quizzes |

### Architecture

- Self-contained single HTML files (no external dependencies)
- Sidebar navigation with scroll spy
- CSS design system with custom properties
- Canvas API for all visualizations
- requestAnimationFrame for smooth animations

See [DASHBOARD_FORMAT.md](DASHBOARD_FORMAT.md) for the complete dashboard authoring guide.

## Pipeline Configuration

`[publish.formats].html` controls **simple** study-guide HTML. Default in the repo may be `false`—check [`publish.toml`](../../publish.toml). Module websites and lab HTML still run when their scripts/pipeline stages request them.

```toml
[publish.formats]
html = false   # Example: simple study-guide HTML off; website generation is separate
```

`generate_all_outputs.py` has **no** `--labs-only` (or `--include-labs`) flag. Labs run on the normal full-course path unless you **skip** them:

```bash
# Default: modules, syllabus, labs, practice tests, exams, websites (unless disabled below)
cd software && uv run python scripts/generate_all_outputs.py --course biol-8

# Skip per-module websites
cd software && uv run python scripts/generate_all_outputs.py --course biol-8 --no-website

# Skip lab manual rendering (PDF/HTML/DOCX for labs)
cd software && uv run python scripts/generate_all_outputs.py --course biol-8 --skip-labs

# Cap how many numbered labs are processed (per-course)
cd software && uv run python scripts/generate_all_outputs.py --course biol-8 --max-lab biol-8:5
```

For a **single** lab file, call `render_lab_manual` as in [§ Lab HTML](#3-lab-html) or see [ORCHESTRATION.md](ORCHESTRATION.md#lab-manual-generation).
