# Output Format: Audio (MP3)

> **Navigation**: [README](README.md) | [Orchestration](ORCHESTRATION.md) | [PDF](OUTPUT_PDF.md) | [DOCX](OUTPUT_DOCX.md) | [HTML](OUTPUT_HTML.md) | [Audio](OUTPUT_AUDIO.md)

Detailed specification for MP3 audio output generated by the cr-bio pipeline.

---

## Overview

| Property | Value |
|----------|-------|
| **Extension** | `.mp3` |
| **Generator Module** | `text_to_speech` (local TTS + ffmpeg) |
| **Key Dependencies** | macOS `say`, `ffmpeg` |
| **Requires Internet** | No for text-to-speech generation |
| **Typical Speed** | ~2–5 seconds per file |

---

## Generation Pipeline

```mermaid
flowchart LR
    MD[Markdown .md] --> EXT[extract_text_from_markdown]
    EXT --> TXT[Plain text]
    TXT --> SAY[macOS say]
    SAY --> AIFF[.aiff temp file]
    AIFF --> FFMPEG[ffmpeg]
    FFMPEG --> MP3[.mp3 file]
```

1. **Text Extraction**: `extract_text_from_markdown()` strips all Markdown formatting (headers, bold, links, code blocks, HTML tags) to produce clean readable text
2. **Speech Synthesis**: `generate_speech()` writes text to a temporary file and invokes local `say`
3. **Encoding**: `ffmpeg` converts the temporary AIFF output to MP3
4. **File Output**: MP3 audio saved to the output path

## Usage

### Python API

```python
from src.text_to_speech.main import generate_speech

# Basic usage
generate_speech("Hello world! This is a test.", "output.mp3")

# With language parameter
generate_speech("Bonjour le monde!", "output.mp3", lang="fr")
```

### Text Extraction

```python
from src.text_to_speech.utils import extract_text_from_markdown

markdown = "# Title\n\n**Bold** text with [link](url).\n\n```code\nblock\n```"
plain = extract_text_from_markdown(markdown)
# Result: "Title\nBold text with link."
```

### CLI

```bash
cd software && uv run python -c "
from src.text_to_speech.main import generate_speech
generate_speech('Your text here.', 'output.mp3')
"
```

## Configuration

### Enable/Disable in Pipeline

In `publish.toml`:

```toml
[publish.formats]
mp3 = false  # Set to true to enable audio generation
```

Audio is disabled by default because it is the slowest format to generate.

### CLI Override

```bash
# Include audio
python publish.py --override-formats pdf,docx,html,txt,mp3

# Exclude audio (faster iterations)
python publish.py --override-formats pdf,html
```

## Runtime Limits

The current backend invokes local commands and enforces subprocess timeouts:

| Constraint | Value |
|------------|-------|
| **Per-file time** | ~2–5 seconds |
| **Command timeout** | 30 seconds by default |
| **Failure mode** | `OSError` wrapping local command failure or timeout |

### Recommended Error Handling

```python
def safe_generate_audio(text, output_path):
    try:
        generate_speech(text, output_path)
        return True
    except OSError as exc:
        print(f"Audio generation failed: {exc}")
        return False
```

The `speech_to_text` module can transcribe audio back to text for verification:

```python
from src.speech_to_text.main import transcribe_audio

transcribed = transcribe_audio("output.mp3", "transcription.txt")
```

## Output Structure

Audio files are generated alongside other formats in the module output directory:

```
module-XX/output/
└── study-guides/
    ├── keys-to-success.pdf
    ├── keys-to-success.mp3    ← Audio narration (when mp3 enabled)
    ├── questions.pdf
    └── questions.mp3
    # Optional: keys-to-success.md, questions.md when [publish.formats].md is true
```
