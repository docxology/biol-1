# BIOL-8 `resources/` — technical documentation

## On-disk layout

In this repository, the only subdirectory under `resources/` is:

```
resources/
├── README.md
├── AGENTS.md          # this file
└── slides/            # Lecture slide PDFs (see slides/README.md and slides/AGENTS.md)
```

There are **no** `reference/`, `media/`, `links/`, or `templates/` directories in this course tree. If those are added later, update this file and [README.md](README.md).

## Slides

- **Path**: `slides/module-N-slides-full.pdf` and `slides/module-N-slides-notes.pdf` (see [slides/README.md](slides/README.md)).
- **Publishing**: Slides are copied from here into `PUBLISHED/biol-8/` by the publish pipeline; they are not generated from markdown in this folder.
