# Course archive

Historical CR-BIO course terms live here. Archived folders preserve the source
course trees and generated publication snapshots that were active for a prior
term.

## Terms

| Term | Contents |
|------|----------|
| [Spring 2026](spring-2026/README.md) | BIOL-1 and BIOL-8 source trees plus their generated `PUBLISHED/` snapshots. |

## Working Rule

Use `course_development/` for the current editable course. Do not run the
publish pipeline from archived source trees, and do not use archived
`PUBLISHED/` folders as live subtree prefixes.

Private folders inside archived course trees remain confidential.
